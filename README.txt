WEB AFILIADOS AMAZON - HTML LOCAL

Uso:
1. Descomprime la carpeta.
2. Abre index.html con doble clic.
3. Edita textos, productos, precios y enlaces de Amazon.
4. Sustituye "tu-tag-21" por tu tag real de afiliado.

Incluye:
- Home
- Categorías
- Fichas de producto
- Reviews
- Comparativas
- Ofertas
- Guías / Blog
- Contacto
- Páginas legales base
- CSS y JS local sin dependencias externas

Aviso:
Los precios, ASIN y textos legales son datos de ejemplo. Antes de publicar, revisa condiciones del programa de afiliados, textos legales y datos reales.
